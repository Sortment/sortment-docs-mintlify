# Sortment Docs (Mintlify)

Source for Sortment's public documentation, rendered by [Mintlify](https://mintlify.com).

- Pages are `.mdx` files with `title`/`description` frontmatter.
- Navigation and redirects live in `docs.json`.
- Images and videos live in `images/`.
- Push to `main` → Mintlify deploys automatically. PRs get preview deployments.

Generated from the GitBook repo `Sortment/sortment-docs` by the migration kit
(`kit/` in the Sortment Onboarding project). Do not edit that repo any more —
this one is the source of truth.
